## 🎯 Quick Start (Full Platform Execution)

### 1. Start Backend API Server
```bash
cd backend
npm install
npm run dev
# Backend API active at http://localhost:5000/api
```

### 2. Start Frontend Web Application
```bash
cd frontend/CivicKuralApp
npm install
npm run dev
# Web application active at http://localhost:5173
```
