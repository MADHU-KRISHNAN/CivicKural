## 🚀 Environment Setup

### 1. Backend Server Setup
```bash
cd backend
npm install
npm run dev
# Starts server on http://localhost:5000
```

### 2. Frontend Application Setup
```bash
cd frontend/CivicKuralApp
npm install
npm run dev
# Starts Vite server on http://localhost:5173
```
